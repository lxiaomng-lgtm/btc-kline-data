# BTC 历史与策略研究

GitHub Actions 在历史归档成功后执行此研究，也支持手动运行。Bitstamp 研究输入由归档与最新快照组成。快照与归档重叠部分逐根核对 OHLCV，空档及最新尾段从 Bitstamp 补齐。快照落后时用尾段补齐，历史文件不受研究任务修改。原 `history/backtests/baseline.json` 停止自动覆盖，旧版本可从 Git 历史追溯。

## 回测口径

- 开发期截至 2023 年，2024 年验证，2025 年起为回溯历史留出；另列 2025 和 2026 两段。1d_08 以北京 08:00 切日。周线按北京时间周一开始，月线按自然月。切分按完整策略 K 线开盘日期，周线和月线的第一笔时间以实际结果文件为准。
- 只用已完成的 K 线。以固定截止点截断输入并重算信号，确认截断前信号与全历史一致。原始跨周期排序按实际已收盘时间。策略由上根完成的 K 线发出信号，下根开盘用同一口径成交；另测再延后一整根策略 K 线。每次买卖分别测试 0.15%、0.30%、0.60%，退出也收费。
- 准则为纯现货多头或现金，百分比收益为区间累计净收益，最大回撤由策略周期收盘净值计算，含最终退出费用，可能低于盘中最大回撤。
- 缠论原型采用方向性去包含、右侧合并 K 线完成后确认分型、异类端点最短间隔和三笔重叠区。进一步等待后续异类分型锁定端点。它由 V7 的笔与重叠区规则改写，未完成严格线段、背驰、三类买卖点与逐信号对照。有效性结论限于这里实现的原型。
- 市场状态由快慢均线、方向与过去价格移动效率识别。综合策略按状态组合趋势、突破及结构权重，日线跨周期版本要求同一时点已收盘的 6 小时趋势确认。
- ETF 及衍生品使用供应商事后历史用于描述性分析。历史首次发布时间、修订记录或延迟不足时，数据不进入回测买卖信号。ETF 两入口均来自同一供应商。

## 三账户

A、B、C 的冻结账本继续按历史记录保留。纯现货现金、持有和买入 10% 后持有和每期维持 10% 是独立研究基准。regime10 将日线状态规则的目标仓位缩放为原来的十分之一。账户实际 CNY 账面收益需要各日冻结仓位、同步 BTC/USD 和 USD/CNY 可执行参考点、完整成交与成本；该库不发布私有账本，也不能由公开价格反推出三账户成交。

日线状态切换进入独立前瞻观察。按 GitHub 公布时刻核对信号的实际可用时间。只有首次公开后的价格才可用于后续前瞻模拟成交及成本计量。对单日成本、延迟与 2025/2026 子期的检验没有产生正式替换证据。
