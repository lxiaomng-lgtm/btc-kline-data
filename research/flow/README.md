# BTC 资金流研究

- `coverage.json` 定量报告源覆盖、缺失、校验失败、公开端点测试与时间戳口径。Binance 公共压缩归档回补 15 分钟 BTCUSDT 现货、USD-M 永续和历史结算费率。OI 回补自 2021-11 起可下载的 5 分钟源快照，只取整 15 分钟事件。OI 保留 BTC 数量单位，禁止与其他所的合约张数直接相加。
- GitHub Actions 的 `btc-flow-interval-datasets` 附件提供北京时间 08:00 对齐的 15m、45m、3h、6h 和 1d CSV。CVD 以主动买入量两倍减总量计算 BTC 增量，这是单一交易所主动成交方向，市场外部资金流入、交易动机或实际开平仓不能由此证实。缺一根 15 分钟本周期 CVD 整段留空；资金费率保留结算所、事件数和区间内费率之和；清算保留明确抽样窗口数，空白不是零。ETF 美国交易日由原始快照与库表保存，不能按中国日线收盘强行分桶。小时 Coinbase 溢价由同时间的 Coinbase/Bitstamp USD 价格计算，本轮另新增 15 分钟实测对齐观察。
- `observations/` 是每次实际云端捕获的独立记录，分开保存源事件钟、采集时刻和允许进入回放的时刻。现货、永续、OI、结算费率与清算记录的来源相互独立。运行时的公开接口权限或状态变化持续记录。ETF 和衍生品的上游不可变来源文件用相对路径关联。旧档案缺历史首次发布时间，不视为严格时点输入。
- `state_returns.csv` 对价格、现货与合约 CVD、OI、资金费率和样本清算构成的候选市场状态做 45 分钟至七天的收益研究。现货买盘主导、合约推升、空头回补、去杠杆、现货承接是与数据相容的模式，不是可证实的交易身份。每个状态、分期、持有期剔除重叠持仓，记录净收益分布、MFE、MAE 和状态持续时间。每边成本假设 0.45%，不是已核验的实际账户费率。按月份分组随机化，分期使用 Holm 校正。
- `lead_lag.csv` 使用负、零和正偏移评估与过去、同期、未来 3 小时价格窗口的关系，按月聚类并应用 Holm 校正。相关不等同于因果。未取得真实发布时间的历史信号全部以事件钟和假设延迟进行描述性回放。
- `research.json` 比较相同样本的价格模型与加资金模型。固定标准化和岭回归，训练只用开发期，2024 验证，2025 起为已见历史对照。阈值是预设的双边费用。输出同期样本数、均方误差、方向准确率、费用后净收益和多重校正后的增量检验。真实前瞻比较采用捕获时点并在样本不足时停在积累状态。增加账户交易信号须另行验收。
- `daily_quality/` 按北京时间日期保存最后一份日内质量报告。报告列出缺失季度小时、影子 45 分钟槽位缺失、工作流失败、报价时序与净值对账。正式 A/B/C 不参与该任务。影子缺口保留并继续记录后续真实报价。
