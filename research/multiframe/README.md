# BTC 日线、3 小时与 45 分钟联合研究

使用已审计的 Bitstamp BTC/USD 现货 K 线。日线按北京时间 08:00 切日，3 小时和 45 分钟从同一日界均匀切分。分段末尾只用已经完整收盘的 K 线，所有策略采用同一个 45 分钟回测时钟和 15 分钟延迟后开盘的成交价。原日线另外用零延迟逐一复核净收益，以与旧报告对齐。每一段从现金开始并在最后一次收盘按该价卖出，所有买卖均计费。

| 家族 | 规则 |
| --- | --- |
| daily | 复用原 08:00 状态切换，目标权重按仓位档缩放，10% 为冻结对照 |
| daily_3h | 日线市场状态限制仓位，3 小时均线判断方向及减仓 |
| daily_45m | 日线限制仓位，45 分钟决定入场、增减仓和退出 |
| 3h_45m | 3 小时方向与 45 分钟入场，日线只用于收益归因 |
| three | 结合日线仓位上限、3 小时方向、45 分钟入场及退出 |
| three_etf | 在 three 上增加核验后基金合计低于 −1 亿美元时减半的条件 |
| three_etf_derivatives | 再用冻结的 OI、CVD、Coinbase 溢价与 OKX 费率快照，存在资金压力时减半 |
| three_chan | 45 分钟确认笔和三笔重叠区原型，结构未转多时目标减半 |

日线过滤家族在多头、震荡分别使用上限的 100%、50%。空头禁买版归零，轻仓反弹版在所用短周期都达到强信号时可用最高 25% 的上限。比较 5%、10%、20%、35% 的目标仓位和每边 0.15%、0.30%、0.60% 的综合交易成本。已成交仓位会随价格变化漂移。信号退出、固定 2 ATR 止损及 3 ATR 移动止损作为三个退出配置。止损只能在信号周期收盘确认，下一次模拟开盘成交。日线＋3 小时止损按 3 小时收盘计算。原日线对照保持其原退出口径。

历史 ETF 事后全表和衍生品合并历史表不能证明过去时点已知。ETF 使用双入口逐基金核对并首存的观测记录，衍生品使用本研究逐次冻结的字段值。两者均从保存的观测时点再延迟 15 分钟才允许进入历史模拟，且通过有效期筛选。缺少当时可用数据时使用下一级策略。报告中的历史覆盖量决定外部数据策略究竟有多少实测证据。

开发期 2022-02 至 2023 年末，验证期为 2024 年，历史留出期从 2025 年初开始。滚动验证用过去 12 个月选择规则，未来半年测试，每折重新从现金开始。选择时要求训练段正收益、最大回撤不高于 12%、至少五笔闭合交易，然后以净收益排序。没有符合条件的参数时，该折持现金。12% 为研究中的风险筛选线。历史留出结果已经公开过，实际前瞻观察用独立记录继续开展。

胜率和实际盈亏比以从空仓到再次清空为一笔完整交易周期，聚合期间全部加减仓和费用。资金利用率为每个 45 分钟收盘的持仓市值占净值的均值。最大回撤检查 45 分钟收盘、成交标记价和期末费用。牛、震荡、空头贡献按该段起点已知的日线状态分配对数收益。未进行杠杆、做空、盘口深度与税务建模。
